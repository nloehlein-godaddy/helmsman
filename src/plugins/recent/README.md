# Recent panel

This independently compiled panel uses only the public `@helmsman/plugin-sdk` types, loading-wheel helper, and version 1 run-read/run-command services. It does not import the application store, renderer, API helpers, or another plugin. The loading wheel is code-native, includes its scoped styles, announces its status, and honors reduced-motion preferences.

Copy this directory outside the checkout, install the published SDK and TypeScript in that author workspace, and run `npm run build`. The output contains the panel module, package descriptor, and locally hosted Phosphor Regular font with its MIT license. The `helmsman.recent` identifier is reserved for the bundled implementation; third-party replacements must use their own plugin identifier while retaining the `helmsman/helm-panel@1` contract.

The panel watches one bounded page in its host-provided galleon scope. Hidden, disposed, and superseded activity stops the watch. Worker outcomes, review recommendations, and source settlement are displayed separately. Commands target an exact original attempt and retain uncertain outcomes in the host journal. Check request only reads a receipt. Retry delivery calls optional `retry({ repo, requestId })` to read the retained original command without reserving identities. An acknowledged or missing entry sends nothing. Older hosts without this method disable Retry delivery while keeping Check request available. Requests requiring Recovery cannot be redelivered here. Accepted and rejected receipts remain visible after reload until the operator dismisses them through the public acknowledgment service. Acknowledgment does not undo a command. Observed spend appears when available.

Panel tests live in `../running/panel.test.ts` and exercise both implementations against the same public service mocks.

Icons use the unmodified Regular WOFF2 from [`@phosphor-icons/web@2.1.2`](https://www.npmjs.com/package/@phosphor-icons/web/v/2.1.2). Glyph mappings follow the package’s `src/regular/style.css`. The font resolves relative to the panel module, so bundled and standalone builds serve it locally. `phosphor-LICENSE.txt` preserves the upstream MIT notice; the bundled app also ships it at `/licenses/phosphor.txt`.
