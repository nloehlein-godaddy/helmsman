# Bugs plugin

Independently buildable page and replaceable panel using only `@helmsman/plugin-sdk`. Build with `npm run build` after installing the SDK. Rename the reserved `helmsman.bugs` package ID and its self-referencing initial-layout contribution ID before packing the resulting `dist` directory through the plugin CLI. Use the [descriptor rewrite and CLI example](../../../docs/plugin-packages.md#opt-in-task-presentation-packages), choosing `example.bugs`. Enable `example.bugs` and open `/plugins/example.bugs/page`.

This package supplies the built-in `/bugs` alias and canonical `/plugins/helmsman.bugs/page` route through operator-controlled page selection. Disabling the selected package shows it as unavailable; it does not restore legacy presentation. Alias cutover acceptance is tracked in the [implementation ledger](../../../docs/plugin-implementation-progress.md). The composition identity is `helmsman/bugs-page`; replaceable panels implement `helmsman/bugs-panel@1`. Saved layouts survive replacement, including intentionally empty layouts; defaults only initialize an absent layout.

Panels inherit the header repository; explicit panel overrides remain scoped by the host. Hidden or suspended panels cancel reads. Source disablement preserves saved selections and reports unavailability.

Unknown metrics remain unavailable, exact zero remains zero, and approximate counts display an approximation marker. Rows lead with the bug title and keep ticket keys secondary. Due dates and observation times use human-readable UTC formatting while retaining exact provider values in time elements. Recognized standalone `S0`–`S5` severity and `P0`–`P5` priority values, including a separator and explanatory text, render as matching accessible badges with the complete provider label retained in tooltips. Ranks 0 and 1 use red, rank 2 uses orange, and custom values remain verbatim. Resolution time explains the 75th percentile separately from the four primary counts, with oldest-open evidence alongside it. Sample size, population, quality, and capped coverage remain explicit. Observation time describes current source status and recent windows, not historical reconstruction.

Rows may include an optional provider-projected plain-text description. The description chevron occupies a dedicated left column and reveals a full-width detail row, keeping collapsed rows compact. It has an action tooltip and accessible name, is keyboard-operable, preserves newlines without interpreting text as HTML, and remembers up to 150 expanded task disclosures by galleon, source instance, and task. Missing or omitted descriptions explicitly report that none is available.

See [installation](../../../docs/plugin-packages.md), [task views](../../../docs/task-source-authoring.md#independent-triage-and-bugs-views), and the [isolated production gate](../../../tests/distribution/task-views-host.pw.ts). The gate covers copied-SDK builds with source access denied, canonical route reload, scope, unavailable providers, restart and visual snapshots.

The composed page owns its heading and Refresh action; standalone panels retain both. The labeled Source selector inherits the header scope without resetting it, omits redundant galleon names, and disambiguates repeated source labels with instance IDs. Same-scope refreshes retain readable last-observed reports and description focus. Failed refreshes explicitly identify retained reports; scope changes and explicit source changes clear them before reading new data. Desktop tables become labeled rows on narrow screens. The bundled Phosphor regular font and license are copied into standalone builds.
